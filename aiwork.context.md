# aiwork.context — GlassMCP

- **Тип продукта / цель:** кроссплатформенное приложение-аналог 9brains-mcp-agent: локальный MCP-сервер (доступ ИИ-чата к файлам/терминалу ПК) + glass-панель управления в браузере. Подключение клиентов через Cloudflare-туннель.
- **Режим:** Продакшн
- **Продакшн-цель:** локальный инструмент пользователя; запускается лаунчером на macOS/Windows/Linux; документация в APP/README.md
- **Стек:** Python 3.12 (портативный, python-build-standalone в ./python, ничего в систему) + FastMCP/mcp<2, uvicorn, starlette, pyyaml; фронт — vanilla HTML/CSS/JS без сборки (static, отдаётся сервером); cloudflared скачивается в ./bin лаунчером
- **Платформы:** macOS (arm64/amd64), Windows (x64), Linux (x64/arm64) — проверка на этой машине macOS arm64; остальные — по лаунчерам с фиксацией как неподтверждённые
- **Современные фишки:** тёмная тема, glassmorphism (backdrop-filter), canvas-фон (mesh-градиент), анимации, prefers-reduced-motion, кастомные контролы без нативных следов, адаптивность
- **Дизайн-направление:** тёмный glass: фон #0a0e17, cards rgba(255,255,255,.04) + blur(20px) saturate(140%), radius 16, акцент-градиент indigo→cyan, Inter/system-шрифты, RU-интерфейс
- **Стандарты UI:** нативных контролов нет; canvas только для декора (aria-hidden, rAF, DPR, пауза при hidden); контраст WCAG AA; focus-visible, aria на кастомных контролах
- **Безопасность:** токен (Bearer / X-API-Key / ?token=), аудит audit.log, зоны подтверждения папок; **режим рабочей папки**: если папка выбрана в панели — ВСЕ операции fs строго внутри неё (realpath+symlink+..-проверка), shell с cwd=папка + deny-паттерны выхода (best-effort, честно задокументировано); dashboard только на 127.0.0.1 (порт 8090), наружу через туннель — только /mcp и /health (порт 8000)
- **Монетизация / лицензия:** нет
- **Установка инструментов:** только в проект (./python, .venv, ./bin); системные установки запрещены
- **Подключённые скиллы:** aiwork; (frontend-design / high-end-visual-design — при полировке UI)
