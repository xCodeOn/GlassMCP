Адрес для клиентов —

Например mcp.example.com или http://203.0.113.5:8000. Схема подставится сама: http:// для IP, https:// для домена.

Это только запись адреса для клиентов: GlassMCP сам не пробрасывает порты и не выпускает сертификат. Подходит, если сервер уже доступен извне — проброшен порт на роутере, свой прокси, VPS или ngrok. Если адрес задан, «Подключение» показывает его вместо туннельного URL.
